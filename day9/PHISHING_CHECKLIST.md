# Phishing Email Recognition Checklist

## Sender
- [ ] Does the display name match the actual email address/domain?
- [ ] Is the domain a lookalike (amaz0n, paypa1, micros0ft)?

## Content
- [ ] Does it create urgency or fear to rush a decision?
- [ ] Is the greeting generic instead of personalized?
- [ ] Is it asking for something unusual (password, wire transfer, gift cards)?

## Links & attachments
- [ ] Does the hovered link match the displayed text/destination?
- [ ] Is there an unexpected attachment type (.exe, .js, macro-enabled doc)?

## If 2+ boxes are checked:
- [ ] Do NOT click or reply
- [ ] Report to IT/security team via the official channel
- [ ] Verify any "urgent" request via a second channel (phone call, Slack) before acting
